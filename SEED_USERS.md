## ⚠️ Important: How Authentication Works

CampusOne uses **Clerk** for authentication. These seed users are **database profiles only** — they don't have Clerk accounts. To test with them:

1. Sign up with Clerk using any email.
2. During onboarding, your Clerk `userId` gets linked to a `UserProfile`.
3. The seed data (schedules, expenses, etc.) is tied to `seed_user_01` through `seed_user_10`.

To **use seed data with your real account**, update the `userId` in the database:
```sql
UPDATE UserProfile SET userId = 'your_clerk_user_id' WHERE userId = 'seed_user_01';
```

## 🔄 Re-Seeding

```bash
# Use cached data (zero API calls):
npm run seed

# Force fresh embeddings (costs Gemini credits):
npm run seed -- --fresh
```

The cache file is at `data/seed_cache.json`. Commit it to the repo so teammates can seed without a Gemini API key.
